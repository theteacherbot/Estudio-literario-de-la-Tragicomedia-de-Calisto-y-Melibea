readme = """# Tragicomedia de Calisto y Melibea — Flipbook interactivo

Flipbook digital e interactivo dedicado al estudio literario de la **Tragicomedia de Calisto y Melibea**, conocida como **La Celestina**, de **Fernando de Rojas**.

## 📖 Características

- Aplicación web en **HTML5**.
- Funciona directamente en el navegador.
- Diseño adaptable a diferentes tamaños de pantalla.
- Navegación mediante efecto de **flipbook**.
- Contenido integrado dentro del propio archivo HTML.
- No requiere servidor, base de datos ni backend.
- No requiere instalación de dependencias para su ejecución básica.
- Puede ejecutarse localmente o publicarse mediante **GitHub Pages**.
