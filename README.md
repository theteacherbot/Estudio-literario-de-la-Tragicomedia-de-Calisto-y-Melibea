# 📖 HTML5 3D Flipbook Viewer

Un visor de libros interactivo (Flipbook) ultraligero, moderno y completamente responsivo, desarrollado con **HTML5, CSS3 (con transformaciones 3D reales) y JavaScript vainilla (Vanilla JS)**. No requiere dependencias externas ni frameworks pesados.

---

## ✨ Características Principales

* **Efecto de Paso de Página 3D Real:** Animaciones fluidas utilizando `transform-style: preserve-3d`, `perspective` y curvas de Bezier personalizadas (`cubic-bezier`).
* **Soporte Multimedia Total:** Capacidad para integrar imágenes, videos con controles de reproducción personalizados y contenido de texto enriquecido o páginas vacías.
* **Lightbox Integrado:** Visor de imágenes y videos en pantalla completa con soporte para zoom táctil/interactivo y desplazamiento por arrastre (*drag & drop*).
* **Diseño Adaptativo (Responsive):** Se ajusta automáticamente a diferentes tamaños de pantalla (móviles, tablets y escritorios) utilizando funciones matemáticas CSS (`clamp()`).
* **Navegación Intuitiva:** 
  * Flechas de navegación laterales.
  * Paginador por puntos interactivos (*dots*).
  * Soporte de diseño dual (dos páginas abiertas) o vista de página única según el espacio disponible.
* **Sin Dependencias:** 100% código nativo, rápido de cargar y fácil de integrar en cualquier proyecto web.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Animaciones 3D, Flexbox, Variables CSS y diseño responsivo)
* **JavaScript (ES6+)** (Lógica de estado, renderizado dinámico y gestión de eventos)
